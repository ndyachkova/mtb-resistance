## Данные для статьи "Интерпретируемая модель машинного обучения для предсказания чувствительности  Mycobacterium tuberculosis к препаратам первой линии"

### Предобработка: аннотация

`annotation/Annotation.py`: преобразование нуклеотидных признаков в аминокислотные, построение агрегированных признаков.

Запуск:

`python3 Annotation.py input='data/vcf_features/' samples='data/all_samples.txt' out='data/features/' thr=0.5 domains='data/domains/`

`input`: путь к папке с vcf файлами для обрабатываемых образцов

`samples`: файл со списком образцов (ID каждого образца с новой строки). Если значение не указано, то обрабатываются все файлы в указанной папке

`out`: путь к папке, в которую будут сохранены списки полученных признаков

`domains`: путь к папке, в которую будут записаны полученные доменные признаки

### Запуск модели для предсказания

Для запуска предсказания модели достаточно запустить файл `code/predict.py`

Параметры:

`feature_lists` - путь к генотипам (спискам мутаций для изолятов)

`out_file` - пусть к файлу, в который будет сохранен результат предсказания. Для каждого из четырех препаратов будет сохранено предсказание модели (0 - образец чувствителен, 1 - образец устойчив) и вероятность того, что образец устойчив.

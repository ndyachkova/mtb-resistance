## Данные для статьи "Интерпретируемая модель машинного обучения для предсказания чувствительности  Mycobacterium tuberculosis к препаратам первой линии"

`lstm_model.py` - код LSTM модели

`gene_domain_pairs.txt` - список использованных пар ген-домен

### Запуск модели для предсказания

Для запуска предсказания модели достаточно запустить файл `code/predict.py`

Параметры:

`res_path` - путь к файлу с информацией об устойчивости

`out_file` - пусть к файлу, в который будет сохранен результат предсказания. Для каждого из четырех препаратов будет сохранено предсказание модели (0 - образец чувствителен, 1 - образец устойчив) и вероятность того, что образец устойчив.

`feature_lists` - путь к генотипам (спискам мутаций для изолятов)
